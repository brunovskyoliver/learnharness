The app mark: a spiral inside a ring, copied from `components/lh-mark.tsx`. Its inks are fixed (white ring, grey spiral `#949494`), so place it on the dark theme's `background` or `surface-raised` only. Its white ring disappears on the light theme: there, set the name in type. No padding is built in; sizing and spacing are the consumer's job. There is no wordmark: set "Brunovský's study" in `title` or `ui` type beside it.
