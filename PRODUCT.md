# Brunovský's study

A learning application for guided lessons, practice, and a persistent knowledge graph.

The learner reads explanations, experiments with demos, and answers questions. The interface must keep the relevant explanation, visualization, and answer accessible together. Lessons and practice retain their existing question mechanics and saved history.

Primary surfaces: home and knowledge graph, chains, new lesson/practice, session transcript and questions, demo workspace, page pane, Library, background activity, settings and setup. Hosted authentication and the Electron shell remain supported. Home leads with "Waiting for you": every unanswered check and open problem, then every lesson whose plan still has unchecked topics, with a Continue that drafts the next topic without sending it (features 002–003). A "Calibration" section shows how stated confidence matched graded results, with the checks answered wrong while Certain (feature 004).

Teacher and practice agents can check computations with Wolfram through a fixed MCP connection (feature 007). Practice accepts a correct answer written in a different form, and a quiz answer checked before it was posed is labelled "Checked with Wolfram" once answered.

Local review examples are available through `npm run dev:review`. They cover lesson/demo exploration, a knowledge check, active practice and practice history. Existing data and edits are preserved; the examples are optional and do not seed hosted tenants. See [docs/ui-review.md](docs/ui-review.md).

The interface uses the Study ink theme (feature 001, 2026-10-27): a warm near-black ground, three inks and one amber accent for the learner's turn, with direct model, reasoning and usage controls in a four-zone prompt bar (turn strip, prompt body, answer well, toolbar). The composer compacts while reading history and expands at the conversation bottom. An active lesson question or practice problem follows it as a compact summary with expandable controls. Scrollbars stay hidden while scrolling remains functional. Settings retain searchable categories, with search across every setting's name and hint and a jump to its row, grouped controls and a live reading preview. Reading preferences, lesson/practice mechanics and saved pane widths remain supported. Legacy arbitrary HTML remains sandboxed and supports whole-demo expansion; individual graph focus requires the demo kit or an explicit adapter. Appearance updates preserve the live demo's parameters, simulation history and camera.

The Library (feature 009) holds the learner's documents and pages, in hosted and desktop versions, and replaces Settings → Files. Uploads never overwrite and deletes confirm. Typing @ in any composer or answer field references an item; the agent receives it in full or as an outline, and a visible label says which. Pages are editable Markdown and math documents beside the chat with restorable versions, written by the learner or the agent. Agent page tools can be turned off in Settings → Agent. An item's content is treated as material, not as instructions.

The ML and LLM lab (feature 008) adds inline and composed panels for real token splits, illustrative attention/sampling/embeddings, computed small networks and tensor shapes. Teacher and researcher agents can look up public Hugging Face configs and papers, search Semantic Scholar with arXiv fallback, and cite up to ten paper pages per turn. Anonymous source lookups are capped at five Hub calls and five paper searches per turn; only queries and identifiers leave the server. ML visuals, Model hub and Papers are independently switchable in Settings → Agent. Token edits stay local to the tokenizer route and never call a model.
