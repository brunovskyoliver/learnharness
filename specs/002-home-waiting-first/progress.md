## Decisions

Agent decisions taken during implementation (reversible, technical, constrained by the spec):

- The waiting item reads `input.statement` for problems and `input.question` for questions; `postedAt` is the posing assistant message's `timestamp` (ms → ISO), else the record's `updatedAt`.
- `Teaser`/`teaserText` moved from `components/question-dock.tsx` to `components/teaser.tsx` (re-exported from the dock) so Home can render teasers without pulling the markdown renderer into its startup graph (`tests/startup-module-graph.test.ts`).
- Shared session list: readers declare demand (`useSessionListDemand`). The list refetches on navigation while at least one reader is mounted (the sidebar while open, Home's waiting list), so Home plus an open sidebar make one request. Difference from before: opening the sidebar on Home no longer refetches, because Home already keeps the list live.
- Teaser math: `repairMathForDisplay` needs KaTeX, which must stay out of Home's startup bundle (`tests/startup-module-graph.test.ts` caught it). The projection applies the repair server-side; the client uses the math-free `teaserPlain`. The dock's `teaserText` is now `teaserPlain(repairMathForDisplay(q))`, same output as before. Contract and data model updated.
- Answer/Solve is a `next/link` styled `prompt-primary` with `data-quiet` (navigation, not a form submit), with `aria-describedby` pointing at the teaser and meta so screen readers hear which item each "Answer" is for. Rows have no hover fill: only the button is clickable.
- Waiting-list failure text: "Could not load what is waiting." with "Try again" (the sidebar's pattern). Loading: two row-height skeletons.
- `?answer=` is dropped with `window.history.replaceState` (documented in Next's linking guide as router-integrated) instead of `router.replace`, so no server round trip. The dock opens two frames after mount, through the same `expandAndReveal` as a click on the bar, so the scroll ends at the true bottom after the reserve settles.
- Graph section: Home owns Expand (in the section header, as in the canvas) and Import notes (header; the import flow moved out of `GraphView`/`MinimalHome`, with a revision counter so the minimal summary refetches after an import). Expanded is the same element restyled `fixed inset-0 z-50`, `role="dialog"` with Close at top left, Tab contained (`containModalTab`), and Escape on document that defers to inner layers (chain table, node menu, menus, other dialogs, tooltips). There is no expand animation, so reduced motion needs no special case.
- Phones: the section header count is hidden (as in the HomePhone artboard); Expand is a 44px icon button with "Expand" as its accessible name, so the header fits on one row at 390px and wraps cleanly at 320px.
- `.prompt-secondary`/`.prompt-primary` are unlayered CSS, so Tailwind padding utilities need `!` to override them.
- `Composer` gained `accessibleName` so Home's field is named by the h1 ("What do you want to learn?" / "What do you want to practice?") while the placeholder says "A topic, a question, or a chapter to work through".
- Sidebar sizes: row titles 15px/20px as in the canvas (were 13px); the Search placeholder and the New label stay 13px because the canvas's 14px is outside DESIGN.md's type scale. Menus use the popover surface (raised-2), 10px radius and no border, as in the canvas. On coarse pointers the field, the filter, New and the menu items grow to 44px.
- The New menu reuses `MenuShell` (placement, arrow keys, focus return) with the sidebar's dismissal contract, now one `useMenuDismissal` hook shared with the filter menu. Lesson keeps `data-testid="new-session"`; Practice keeps `new-session-practice`.
- Graph display settings: Settings already had a Graph section (Extraction, Graph rendering, chunk budget). The display controls join it as a "Display" group (`components/settings/graph-display-section.tsx`), loaded from and saved to `/api/graph/render-settings` (debounced 400ms, as before), and each save calls `notifySettingsSaved("graph")`. `GraphView` no longer writes settings; it reads them on mount and on that signal. Load and save failures show in words.
- Phone scroll band: one "Scroll to latest" button renders at a time (a `matchMedia` hook picks the band below 640px, the corner button above), so selectors always find the visible one. The band stays mounted until a jump settles: unmounting it at the at-bottom threshold shrank the reserve mid-motion and the clamp cancelled the expand (found by the dock smoke test).
- `scripts/smoke-sidebar-ui.mjs` expected prose `h2` weight 700; feature 001 capped Newsreader headings at 600 (DESIGN.md) and never ran this script. The assertion now expects 600.

## Report

**What changed**
- Home (`components/home.tsx`): one scrolling column — h1 and the topic composer, "Waiting for you" (`components/waiting-section.tsx`), then the "Knowledge graph" section with counts, Import notes and Expand. The centred-icon empty states are gone.
- Waiting data: `src/core/waiting.ts` projects an allowlisted `waiting` item (tool call id, kind, action, teaser, posted time) onto each chat summary; one kind-label mapping is shared with the prompt bar. Answer/Solve link to `/chat/<id>?answer=<toolCallId>`, which opens the dock expanded at the bottom and drops the param.
- Shared list: `components/session-list.tsx` holds the `/api/chats` snapshot for the sidebar and Home.
- Graph: `GraphView` section mode (420/260px box, Expand to a full-screen dialog without remount); Import notes moved to the section header; the gear and its popover moved to Settings → Graph → Display (`components/settings/graph-display-section.tsx`); the chain table covers the Home content area (`components/overlay-host.tsx`); `MinimalHome` fills the same box when rendering is off.
- Sidebar: Search with the filter inside, a labelled New menu (Lesson, Practice), amber waiting dots, wrapping 15px titles, Newsreader date shelves.
- Queued steers: `DELETE /api/chats/[id]/steer/[steerId]` and `cancelUserSteer` withdraw an undelivered steer from the registry and the live agent's queue; rows get a ×, with "Already sent" / "Could not remove" notes.
- Phones: scroll-to-latest sits in a 48px ground band above the prompt bar.
- Event stream: closed on `pagehide` and reopened on a restored `pageshow`, fixing the stall after six full navigations.
- Tests and scripts: 10 new or extended test files (2515 → 2557 tests); `smoke-sidebar-ui.mjs` and `check-turn-navigation-ui.mjs` cover the new header and the phone band; dock-smoke race fixes (`waitForStableTranscript`, scroller capture order).
