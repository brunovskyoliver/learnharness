- Agent (phase 4): the server names the passage only when the model answers (`phase: writing` with the quote), so the pencil underline and breathing blot show then, and the question is held back for Riddled's on-screen time `min(width/650 s, 1.6 s) + 1.3 s` (§10.2) before it inks in. While the model thinks, only the corner hint says "Reading…". Reduced motion: no hold.
- Agent (phase 4): the reading blot sits 10 px after the passage's last line (§10.2, frame sheet-03 tile 7), not in the margin gutter as ui-contract says; the frame and the reference CSS agree, so the frame wins. It can overlap the next words when the passage ends mid-line, as Riddled's does.
- Agent (phase 4): ink dots and the reading blot use our own blob (the §10.4 splash recipe with our seed), not Riddled's logo glyph, as phase 3 did for the reviewer picker.
- Agent (phase 4): margin notes are 15 px (not ≈16) on a 23.5 px line and 384 px wide (not ≈376): at those values every line of the four frame notes breaks where the frame breaks. Gap between stacked notes 14 px; "{n} replies" 12/16 px, 8 px under the last line; dots 36 px left / 51 px right of the column; right note text at +71 px.
- Agent (phase 4): crowded notes settle as a packed cluster placed by least squares around their passages (so a note can move up as well as down); it reproduces the frame's 287/466/598 for passages at 377/469/501 within 2 px.
- Agent (phase 4): tethers: a fresh note's tether draws once (tie then spine) and stays; other notes show the faint tether only while the pointer is on them (frame margin-notes: only the hovered note has one). Faint spine opacity .16 (no CSS for it).
- Agent (phase 4): only his edits start the pause (the editor must have focus); loading or normalizing a page never starts a read. A refused read (503) and a failed one show in the corner hint ("No model set up. Open Study's settings" opens Study's settings dialog in place; "That didn't come through. Try again"). The faux engine's think time is `LH_NOTEBOOK_FAUX_MS` (1500 in Playwright) so Stop and typing can land mid-read.
- Agent (phase 4): margin notes hide in Marks only and below 768 px (phase 5 brings marks); collapsed notes show the whole first message (phase 5 adds the clamp and expansion). Inline replies render a sketch as its finished last step (stepper in phase 6). Detached threads stack at the top of the right margin with "The words this was about are gone."
- Agent (phase 4, phase 3 fixes): `.nb-prose p { margin: 0 }` outweighed the 1.05em block gap, so a paragraph after a list or another paragraph had no gap; now `:where()`. The left-edge hover now starts on a real pointer move: the browser's synthetic pointerover at (0, 0) when a page loads opened the sidebar in headless runs (flaky note.spec); e2e test added.
