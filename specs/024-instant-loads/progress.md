- Scope (owner, 2026-11-09): all four — PDF ranges + caching, cached plot libraries, lighter plotly build, trim page-load JS.

- Gate 2 (owner "go", 2026-11-09): implement everything; medium findings fixed in spec (mid-read file replace = known limit; hand-written demos keep full plotly).
- Commits: one per phase on main, only feature files (app/globals.css waiting-row fix stays uncommitted, not part of 024). No push/deploy.
- Phase 2 (agent, technical): content route sends `Cache-Control: private, no-cache, no-transform`; `no-transform` is what keeps Next's built-in gzip (router-server `compression`) off text/bmp items, so the contract's "never content-encoded" holds. ETag = first 32 base64url chars of sha256(id, size, mtimeMs), quoted (strong). `openDocumentStream(file, pick)` opens one handle and lets `pick` choose range/all/none from that handle's own size+mtime (same inode as the lstat check), so tag and bytes always agree.
- PDF revision (owner, 2026-11-09, after T009 showed 8.6 s): "Versioned chunks" — custom pdf.js range transport, chunk URLs carrying the version tag, immutable private caching, parallel fetches. Chunk size by measurement.
- PDF target (owner, 2026-11-09): accept ~2–2.5 s cold with the first-chunk-in-parallel tweak; SC-001 now ≤2.5 s cold / ≤0.8 s reopen. No compacted copy.
- Scanned note (owner, 2026-11-09): check pages 1–3 only.
- Blank flash (owner, 2026-11-09): add the cold-load chat transcript discard (~150–360 ms blank; likely a mount-time provider update above the chat Suspense boundary in app/(app)/layout.tsx) to this feature.
- Renderers (owner, 2026-11-09, after phase 5 measurement): math eager (KaTeX server-rendered as today), only the code highlighter on demand. Agent decision: code messages don't wait — streamdown already shows plain code until the highlighter answers, as today; so no waiting look is needed and T026 is moot.
- Blank-flash fix (owner, 2026-11-09): subscriptions — the six shell providers hand down stable values and consumers subscribe (useSyncExternalStore); no visible change, mobile menu stays fast.
