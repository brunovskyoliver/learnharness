- Agent (T001, Next 16.3.2 docs + app-router source): no breaking change to `useRouter().push/back`, `useSearchParams` or `usePathname`. Points that shape R9: `router.push` takes no history state, and Next's HistoryUpdater writes a fresh `history.state` (`__NA`, the tree) on each push; custom keys survive only when added afterwards with `history.replaceState({ ...history.state, key }, "")` (data carrying `__NA` passes Next's patch untouched). So the nonce is written into the Library entry right after the push commits; if a later Next write drops it, the pill falls back to `router.push("/chat/{id}")` as R9 already says. `useSearchParams` in a prerendered route wants a Suspense boundary. Cached routes stay in the DOM under React Activity (`display: none`), so the focus-return query and e2e selectors must take the visible match.
- Agent (T002, reversible): the plan's baseline commit adc0021 was measured by 026 with the same script on 2026-11-08 and is reused (`~/agent-runs/2026-11-08-reference-chips/startup-base.json`); 19730c2 (026 landed, no 027 code) measured fresh: / 254,005, /chat/new 243,561, /library 266,080 gzip bytes (`startup-before.json/.md`). SC-006 stays against adc0021; /library has about 8.3 KB gzip of headroom left.
- Agent (T053, what 026 stores): `nameTable` offers a live mirrored item's full Library path (`libraryPathName`: every ancestor folder, the linked folder, the repo path, "/"-joined) at rank 2 and its `previousNames` (old paths) at rank 1; a removed mirrored tombstone offers no current name, only `kept.previousNames` (its last path) at rank 0, so `@notes.md` never reaches it. `LibraryReference.name` for a mirrored reference is the item's display name (the file name), never the path; `fromRepo: true` marks it. A tombstone's `removedBecause` is `"repo" | "unlinked"`; the client never sees tombstones (`GET /api/library` lists live items and folders only). The learner wording is `REMOVED_FROM_REPO` (" · Removed from the repo") and `goneSuffix(ref)` in src/core/library-refs.ts.
- Agent (T054, reversible): so `removed` is decided from the reference's own `fromRepo` flag: an id in neither the live list nor the Trash is `removed` when the caller passes `fromRepo`, else `deleted` (components/reference-catalog.ts `itemStatuses`). Open for T055: a removed mirrored reference's sent token is its old path, which the client cannot rebuild (no tombstones, and the reference stores the file name), so the catalog entry built from the reference's name will not cover `@{path}`; T055 needs a source for that path.
- Agent (phase 1-2, reversible): `referenceSpans` normalises one run at a time (a non-mark code point and its marks) to map NFC offsets back to raw ones, and falls back to normalising prefixes when the runs don't add up to the whole NFC text (rare scripts). `parseReferences` is now the distinct entries of `referenceSpans`; the server's behaviour is unchanged (all its tests pass unchanged).
- Agent (phase 1-2, reversible): `referenceForms` returns one form per span (whole-item forms included) plus a passage-only form for each unclaimed `<library_passage>` outside code, sorted by start. Passage-only forms carry the block's `page` too, for the "· p. {n}" hint that replaces "Sent from page {n}".
- Agent (phase 1-2, reversible): `parseLibraryHref(href, origin?)` accepts an absolute URL only when it is on the given origin (callers pass `location.origin`); without one, only paths. `libraryHref()` builds `/library?item=…[&page][&quote]` with `citationHref`'s encoding.
- Agent (phase 1-2, reversible): `chipTarget` hints carry their separator ("· p. 4", "· {first line}"). A PDF passage chip is named by its page ("Open Notes.pdf, page 4") with the passage as its description. A trashed item with no known entry opens `/library?view=trash`. Deleted and removed chips are plain text that reads "{name} · no longer in your Library" / "{name} · Removed from the repo", with no hint.
- Agent (phase 1-2, reversible): the 44px coarse-pointer hit box is an invisible `::before` on the link rather than `inline-flex`, so a chip's name can still wrap inside the line at 320px.
- Agent (phase 1-2, reversible): `seedReferenceLesson(request, { remote? })` makes the "other" item by writing it into catalog.json (no upload extension maps to `other`); the mirrored pair is linked through the real 026 routes against the fixture remote, only when one is given. references-card.tsx now reads the live list from reference-catalog (same 30s TTL, also dropped on `library-changed` while a catalog hook is mounted).
